## Course requirements checklist

The following is a summary of the supplied Mini Project Guidelines and DSAI 523 Assessment Booklet, not a claim that these features are implemented.

- [ ] Form a team of exactly four members.
- [ ] Choose an application domain and document the design.
- [ ] Build a working application (Python and Flask are the suggested stack; alternatives are allowed).
- [ ] Provide REST CRUD services with appropriate HTTP response codes (20 points).
- [ ] Integrate an external REST service (20 points).
- [ ] Persist information in an external cloud database (20 points).
- [ ] Document code and maintain this README (10 points).
- [ ] Select a bonus route (up to 30 points): demonstrate load balancing/scaling; implement three listed security features; or obtain instructor preapproval for another relevant cloud feature.
- [ ] Keep the complete code in a publicly accessible GitHub repository.
- [ ] Record a live demonstration of at most 15 minutes, with every member appearing and explaining their contribution.
- [ ] Begin the video with the project name, group number, and all members' full names and student IDs.
- [ ] Submit the repository and accessible video links on Moodle by **7 December 2026, 23:59** (as written in the booklet).

The mini-project is worth 25% of the final course grade. The guidelines specify YouTube for the video; the booklet also allows Google Drive or another accessible platform. YouTube satisfies both. Confirm any conflicting rubric wording with the instructor: the guidelines also contain older 10/15-point wording alongside the 100-point breakdown above.

## Team workflow

Create a branch for each change, open a pull request, and ask another teammate to review it before merging. Keep the README updated with setup instructions, API examples, deployment details, and each member's contribution as implementation proceeds.
