# Project context

This is the DSAI 523 Cloud Computing and Distributed Systems mini-project workspace. Read README.md for the course requirement summary and current status.

## Current state

Only repository documentation and ignore rules exist. No application domain, dependency manifest, implementation, test suite, or deployment has been selected. Do not claim the project runs or passes tests until commands exist and have actually been executed.

## Implementation guidance

- Follow the team's selected application domain. If none has been selected, propose a small set of options before implementing a full application.
- Python and Flask are the course's suggested stack; document an intentional alternative if selected by the team.
- Provide REST CRUD endpoints with appropriate status codes, an external REST integration, and persistent storage in an external cloud database.
- Local database substitutes may support development and testing but do not fulfill the cloud database requirement.
- Document setup, environment variable names, API requests/responses, tests, deployment, and limitations as each feature is added.
- Add reproducible dependencies and meaningful tests alongside implementation. Mock external services in automated tests where practical.
- Keep credentials, database URLs containing passwords, API keys, student IDs, and private contact details out of source control. Use placeholders in .env.example.
- Obtain the team's choice of bonus route; an alternative bonus feature requires instructor preapproval according to the guidelines.
- Keep scope understandable so every member can demonstrate and explain their own contribution.

## Validation

There are no build, lint, or test commands yet. Establish them when application code is introduced and record the exact commands in README.md and here. For documentation-only changes, check consistency and links; do not invent passing test results.
